# English content archetypes

Use the article type that matches the reader's task instead of filling every guide with the same sections.

## Beginner lesson

Goal, prerequisites, minimal action, expected multi-tick result, targeted troubleshooting, completion check, next lesson.

## Diagnostic guide

Symptom, observable state, return-code branch, read-only probe, likely causes, repair, later-tick verification.

## API reference

Method purpose, arguments, ownership and timing rules, return values, minimal example, boundaries, official source.

## Concept guide

System model, relationships, tradeoffs, diagrams or state tables, application examples, related APIs.

## Case study

Real starting state, evidence, hypothesis, intervention, measured result, limitations, reusable lesson.

A case study must not be published until the underlying Console or live-room evidence has been accepted.
