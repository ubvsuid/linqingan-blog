## 本批关键修正

### RawMemory segments

- 补齐请求激活、下一 tick 可读和写回的完整时序；
- 区分 `undefined` 与空字符串；
- 增加 ID、激活数量和单 segment 大小限制；
- 损坏 JSON 时停止写入，避免覆盖原内容；
- 增加版本字段、多个 segment 合并请求和调度边界；
- 离线覆盖未加载、空内容、合法 JSON、损坏 JSON 与非对象 JSON。

### 全局缓存

- 区分局部变量、模块全局变量与 Memory；
- 明确不跨 tick 缓存 live RoomObject；
- 使用按房间 `Map`、版本号、TTL 和 ID 恢复；
- 解释全局重置后的自然重建；
- 增加不同类型数据的失效策略和性能测量边界；
- 离线覆盖缓存命中、到期重建、房间隔离与空缓存重建。

### CPU 监控

- 区分 `getUsed()`、`limit`、`tickLimit` 与 `bucket`；
- 增加测量函数和固定长度样本窗口；
- 同时记录当前值、平均值、峰值和 bucket 状态；
- 解释首次访问 Memory、全局重置和输入规模对结果的影响；
- 明确 Simulation 环境不能用于评价在线 CPU；
- 离线覆盖窗口淘汰、空样本、平均值与最大值。

### Room 事件日志

- 修正原文“本 tick 事件”为官方定义的“上一 tick 事件”；
- 区分默认解析数组与 `raw` JSON 字符串；
- 按事件类型说明不同 `data` 字段；
- 增加己方目标受击筛选、目标或攻击者已消失的处理；
- 区分当前动作返回值与下一 tick 事件记录；
- 离线覆盖攻击过滤、缺失目标、非己方目标和其他事件类型。

### 市场订单创建

- 区分创建订单、直接成交、调价、扩量与取消；
- 增加参数、己方 Terminal、重复订单和 Credits 检查；
- 明确 5% 挂单费用和取消不退款；
- 使用一次性 Memory 请求，调用前关闭开关，避免每 tick 重复执行；
- 保存 API 返回值、费用和执行状态；
- 记录官方页面中 300 与 50 两种订单上限文字不一致，不在代码中硬编码；
- 离线覆盖参数无效、费用不足、重复订单和可提交场景。
