# Site Intelligence Action Queue V2

The Action Queue is a rule-based recommendation layer above Signals V2. It does not query source systems directly and does not calculate a composite SEO score.

## Stable Action identity

Action IDs are semantic hashes based on category, Asset, related Asset, and the issue key. Row order and mutable metrics are excluded. The same continuing issue therefore remains the same Lifecycle Action as metrics change over time.

## Priority safety

P0 remains narrow:

- same-language GSC Owner mismatch / cannibalization;
- explicit upstream GSC P0 snippet/ranking opportunity.

Behavior cannot independently manufacture P0. A missing same-language Owner becomes mapping/research work rather than cannibalization.

P2 may be promoted to P1 by multiple mature source families, but corroboration never creates P0.

Every Action retains source Signal IDs and rationale. No Action automatically edits content, metadata, URLs, redirects, or deployments.
