# Community reference policy

External links and community references must be earned through useful, accurate work. Do not create artificial backlinks, paid link exchanges, fabricated testimonials, or unverifiable endorsements.

Suitable outreach material includes:

- Reproducible Screeps case studies with accepted live evidence.
- Free tools with documented calculation boundaries.
- Corrected API or return-code references.
- Public fixes contributed to relevant projects or discussions.

When a legitimate external reference appears, record the source, destination page, date, context, and whether the reference remains live during the quarterly review.
